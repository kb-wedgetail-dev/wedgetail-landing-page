# Wedgetail Technology — Coming Soon

Static coming-soon landing page for Wedgetail Technology, hosted on GitHub Pages.

- `index.html` — the page (no build step)
- `assets/` — images, fonts, favicon
- `.nojekyll` — tells GitHub Pages to serve files as-is

GitHub Pages is configured to publish from the `main` branch root, so every push to `main` goes live within a minute or two.

Local preview: open `index.html` in a browser, or run `python -m http.server 8080` and visit http://localhost:8080.
